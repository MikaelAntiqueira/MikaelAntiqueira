## 🚀 Projeto em destaque

### 🚚 [TMS Fretes SOMA](https://github.com/MikaelAntiqueira/-tms-fretes-soma)

Sistema de inteligência sobre o transporte do Grupo SOMA/RS: compara **Frete Cotado × Frete Contratado** para decidir e negociar com base em dados.

| | |
|---|---|
| **Problema** | Várias transportadoras, cotações e faturas sem uma visão única de quanto se pagou frente ao que foi cotado |
| **Solução** | Cruzamento de cotações, contratações e faturas com indicadores por transportadora, rota e período |
| **Stack** | Next.js 14 · TypeScript · Tailwind CSS · Supabase (Postgres + Auth) · Vercel · Python |
| **Status** | 🟢 Em produção · [abrir aplicação](https://tms-fretes-soma-app.vercel.app) |
