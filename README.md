## O que eu faço

Não sou desenvolvedor de software no sentido tradicional. Minha posição é:

> **Alguém que entende o problema de logística e usa IA como ferramenta para construir soluções práticas.**

Isso me permite:
- Resolver problemas reais de logística com ferramentas que a maioria das pessoas não usa

- Usar IA como parceira de trabalho, não como buzzword

## Meu diferencial

Raramente você encontra alguém em logística que:

1. **Entende o problema de negócio** (não só executa, mas pergunta por que e como melhorar)
2. **Usa IA como ferramenta real** — não para gerar texto, mas para construir coisas que resolvem problemas
3. **Entrega sistemas que funcionam** — dashboards em produção, automações que rodam, APIs que integram

Esse é o meu "plus". Não é comum ver isso em logística.

## Projetos

### 🚚 TMS Fretes SOMA

Repositório: [github.com/MikaelAntiqueira/-tms-fretes-soma](https://github.com/MikaelAntiqueira/-tms-fretes-soma)

**O que é:** Um TMS (Transportation Management System) para comparar Frete Cotado × Frete Contratado no grupo SOMA/RS.

**O que faz:**
- Coleta cotações de múltiplas transportadoras
- Cruza com contratações e faturas
- Gera indicadores de desempenho (por transportadora, lane, período)
- Dashboard em produção em [tms-fretes-soma.vercel.app](https://tms-fretes-soma.vercel.app)

**Tecnologias:** Next.js 14, TypeScript, Tailwind CSS, Supabase (Postgres + Auth), Vercel, Python (pipeline de dados).

**Status:** Em produção.
